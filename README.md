# SubTrack – Smart Subscription & Free-Trial Management Platform

BCA Honours Semester 6 individual project by Sivalakshmi PS.

SubTrack helps users manage digital subscriptions and free trials in one place:
renewal reminders, expense analytics, usage tracking and rule-based recommendations.

## Tech Stack
HTML, CSS, JavaScript, Bootstrap, Chart.js, Node.js, Express.js, MongoDB Atlas, Mongoose

## Setup
1. Clone the repo and run `npm install`
2. Copy `.env.example` to `.env` and fill in your values
3. Run `npm run dev`
